# AutoSkeleton — Docs & Demo Site

[![Live site](https://img.shields.io/badge/live-autoskeleton.com-7c3aed)](https://www.autoskeleton.com)
[![npm](https://img.shields.io/npm/v/@gyojiro/autoskeleton-react.svg)](https://www.npmjs.com/package/@gyojiro/autoskeleton-react)

The documentation, component gallery, and live demo site for [**AutoSkeleton**](https://github.com/Eunjiro/autoskeleton) — a TypeScript-first React library for building skeleton loading UIs.

**🔗 [www.autoskeleton.com](https://www.autoskeleton.com)**

Built with Next.js (App Router) and Tailwind CSS, and uses [`@gyojiro/autoskeleton-react`](https://www.npmjs.com/package/@gyojiro/autoskeleton-react) throughout — every skeleton on this site is the real component, not a mockup.

## What's here

- **`/docs`** — installation, setup, theming, dark mode, accessibility, and full API reference
- **`/components`** — all 26 components, each with a live preview paired directly with the code that produced it
- **`/examples`** — 23 real-world layouts (profiles, dashboards, product cards, forms, chat) composed from the library's primitives

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm run lint    # eslint
```
