# Contributing to AutoSkeleton

This document describes contributing to the AutoSkeleton **library**
(component source, tests, Storybook) — not this docs/demo site. Its
canonical version lives in the
[`autoskeleton`](https://github.com/Eunjiro/autoskeleton) repo:

**[docs/CONTRIBUTING.md](https://github.com/Eunjiro/autoskeleton/blob/master/docs/CONTRIBUTING.md)**

If you have `autoskeleton` cloned alongside this repo, you can also read it
directly at `../autoskeleton/docs/CONTRIBUTING.md`.

If you're looking to contribute to *this* site instead, there's no
dedicated guide yet — open an issue or PR against
[`autoskeleton-web`](https://github.com/Eunjiro/autoskeleton-web) directly.
